This is a web application that aggregates job listings from multiple sources and displays them in a single place. It is built with NextJs and Supabase.

## Features

- Creates job offers manually and manage them
- Creates search criteria for jobs by keyword
- Scraps job listings from different sources based on your seach criteria

## Stack

- [React](https://reactjs.org)/[NextJs](https://nextjs.org/)
- [Supabase](https://supabase.com/) (Postgres, Auth, Edge functions)
- [Vercel](https://vercel.com/)
- [Puppeteer](https://pptr.dev/)
- Github Actions
