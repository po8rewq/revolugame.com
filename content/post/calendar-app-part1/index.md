Welcome to a new series of posts about building a calendar app. In this series we will build a calendar app from scratch. We will use the following technologies:

 - React and bootstrap for the UI (using styled-components)
 - zustand for the state management
 - Firebase for the database and the authentication

Each part of the series will be a self-contained post talking about one topic. The topics will be:

 - Part 1: Setup the project
 - Part 2: Create the UI
 - Part 3: Add the state management
 - Part 4: Add the database
 - Part 5: Add the authentication
 - Part 6: UX improvements (drag and drop, etc.)
